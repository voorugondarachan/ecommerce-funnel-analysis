# E-Commerce Funnel, Cohort & Revenue Analysis

## Overview
End-to-end analysis of an e-commerce dataset covering user behavior, 
conversion funnels, cohort retention, and revenue performance.

## Tools Used
- MySQL — data modeling, SQL analysis
- Power BI — interactive dashboard and visualization

## Project Structure
- funnel_analysis.sql — complete SQL queries
- Funnel_Analysis.pbix — Power BI dashboard

## Key Findings
- Checkout stage has the highest drop-off at 45%
- Mobile drives 55% of total revenue
- Organic traffic outperforms paid at every funnel stage
- 2020 cohort generated highest lifetime revenue at $1.7M

## Techniques Used
CTEs, window functions, LAG/LEAD, cohort analysis, 
TIMESTAMPDIFF, revenue segmentation, NULLIF for safe division
